# fastapi tracks — so bumping any one alone fails to resolve. The previous
# comment here concluded starlette 1.x was "incompatible with fastapi 0.115";
# that was true only because fastapi was held back. With fastapi >= 0.140 the
# whole chain resolves cleanly.
